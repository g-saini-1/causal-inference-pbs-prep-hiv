# Data dictionary

Column definitions for the three synthetic, analysis-ready CSVs in
[`data/synthetic/`](synthetic/). These are generated by
[`src/generate.py`](../src/generate.py) (seed `20180401`) and are described in
full in [`reports/data_acquisition.md`](../reports/data_acquisition.md).

Real-world source extracts (raw PBS Item Reports, NNDSS/Kirby HIV notification
tables, PBS item/drug maps) live under [`data/raw/`](raw/) and are documented
inline in [`data/raw/data-collection-notes.md`](raw/data-collection-notes.md).

## `pbs_dispensing_monthly.csv`

One row per state × month, January 2016 – December 2022.

| column | type | meaning |
|---|---|---|
| `state` | string | one of `NSW`, `VIC`, `QLD`, `WA`, `SA`, `OTHER` |
| `month` | date (`YYYY-MM-01`) | first day of the dispensing month |
| `prep_dispensing_count` | integer | synthetic PBS-derived PrEP dispensing count for that state-month |

Built-in patterns: a NSW-only early ramp from March 2016 (EPIC-NSW
demonstration trial), a large national level shift and 6-month ramp from
April 2018 (PBS listing), and a COVID-19 dip from March 2020–October 2021,
deepest and longest in VIC.

## `hiv_notifications_quarterly.csv`

One row per state × transmission category × quarter, 2013Q1–2022Q4.

| column | type | meaning |
|---|---|---|
| `state` | string | one of `NSW`, `VIC`, `QLD`, `WA`, `SA`, `OTHER` |
| `quarter` | string (`YYYYQn`) | quarter label |
| `quarter_start` | date | first day of the quarter |
| `transmission_category` | string | `MSM`, `Heterosexual`, or `Other` |
| `hiv_notifications` | integer | synthetic HIV notification count |

Built-in patterns: a mild shared secular decline across all categories; a
PrEP-driven reduction (ramping to ~42% relative) applied only to the `MSM`
category, starting 2016Q2 for NSW (EPIC-NSW) and 2018Q2 for all other states
(PBS listing); a shared testing-disruption dip in 2020–2021H1, worst in VIC.
`Heterosexual` and `Other` never receive a treatment effect. They are the
difference-in-differences control group. National annual totals are
calibrated to track the published anchor figures (1,028 notifications in
2015, 838 in 2018).

## `state_covariates.csv`

One row per state, containing static (or slow-moving) state-level attributes
used for the optional heterogeneity / causal forest analysis.

| column | type | meaning |
|---|---|---|
| `state` | string | one of `NSW`, `VIC`, `QLD`, `WA`, `SA`, `OTHER` |
| `population` | integer | illustrative state population |
| `msm_pop_proxy` | integer | illustrative MSM population proxy |
| `irsd_socio_index` | integer | illustrative socioeconomic disadvantage index |
| `urbanicity_index` | float | illustrative urbanicity index (0–1) |
| `baseline_hiv_testing_rate_2017` | float | illustrative pre-listing HIV testing rate |
| `covid_lockdown_severity_2020` | float | illustrative 2020 lockdown severity index (0–1) |
| `epic_nsw_early_access` | integer (0/1) | 1 for NSW (EPIC-NSW early-access state), else 0 |

None of these covariate values are real ABS/Kirby figures. They are
plausible, hand-set constants for demonstrating heterogeneous treatment
effect estimation.

## Legacy files

`data/synthetic/legacy/` holds two earlier, superseded iterations, kept for
provenance rather than for active use:

- `v0.1_pre_qa_fix/`: the generator output before the two QA fixes described
  in `reports/data_acquisition.md` (the April-2018 dispensing-dip artifact and
  the shared-RNG coupling between datasets).
- `panel_quarterly_2013-2022_v0/`: an earlier, differently-structured panel
  design (state × exposure-category × quarter, 2013–2022, with pre-merged
  `analysis_panel.csv`) from before the current monthly/quarterly split.
